# SmartParallel v1.0 benchmarks — archived

> **Archived documentation:** SmartParallel v1.0.

The original v1.0 benchmark suite is preserved under [`benchmarks/v1.0.0/`](../../benchmarks/v1.0.0/README.md). It includes:

- OpenCV threshold, convolution, Sobel, and stress workloads;
- numerical integration, heat diffusion, and irregular-particle workloads;
- decision-quality and `parallel_for` overhead audits;
- recorded CSV data and generated PNG/SVG figures.

These results remain useful historical evidence, but they are not the authoritative v1.1 performance report. See the [v1.1 real-world results](../v1.1/benchmarks.md).
