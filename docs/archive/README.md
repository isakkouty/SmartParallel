# Documentation archive

This directory preserves historical SmartParallel material for traceability. It is not the authoritative documentation for the current release.

- [`beta/`](beta/) — pre-v1 design and beta documentation.
- [`pre-v1.1-documentation/`](pre-v1.1-documentation/) — the former mixed `docs/v1` tree, retained exactly as it existed before the public v1.1 documentation cleanup.
- [`v1.1-development/`](v1.1-development/) — internal implementation updates, milestone notes, installation notes, and the detailed development changelog.
- [`validation-history/`](validation-history/) — release gates, safety reviews, and local validation reports.

Use [`../v1.1/`](../v1.1/README.md) for current documentation and [`../v1.0/`](../v1.0/README.md) for the historical v1.0 release summary.
