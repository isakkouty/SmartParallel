# SmartParallel v1.8 — Exact-archive validation

The release workflow validates the exact source ZIP rather than trusting the original working tree.

Required checks:

1. generate two deterministic archives and require byte-for-byte equality;
2. compute the source ZIP SHA-256;
3. extract into a fresh directory;
4. reject duplicate or unsafe ZIP entries;
5. verify `SOURCE_MANIFEST.sha256`;
6. configure and build without relying on the original build tree;
7. run the complete supported test suite;
8. run the v1.8 benchmark smoke;
9. validate documentation from the extracted archive;
10. exercise optional oneTBB and OpenCV paths where available.

The exact archive produced after the final documentation corrections must be revalidated. The final checksum and platform-specific logs are generated by the release scripts and must be retained with the publication evidence.
