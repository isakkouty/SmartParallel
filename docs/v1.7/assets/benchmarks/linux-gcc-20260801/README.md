# SmartParallel v1.7 accepted benchmark assets

This directory retains the accepted Linux/GCC validation evidence generated from the v1.7 source before release packaging. The raw CSV, summary, metrics, publication report, and SVG plots are machine-specific. The `cross-process/` directory contains the byte-identical replay manifests and unchanged Approved profile from the strided heat-diffusion proof.

SHA-256 provides evidence-integrity detection only. It does not authenticate organizational approval or authorship.
