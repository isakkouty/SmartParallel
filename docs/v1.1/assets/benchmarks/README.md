# Generated benchmark assets

> **Benchmark assets:** final v1.1 performance evidence retained by the current [v1.3 portability release](../../../v1.3/README.md).

These figures and generated metric files are produced from the final checked-in real-world CSVs by:

```text
python tools/plot_real_world_results.py
```

The script validates required columns, correctness, backend authentication, and the four-participant budget before writing output. PNG files are used by the Markdown report; SVG files are retained for scalable publication output.
